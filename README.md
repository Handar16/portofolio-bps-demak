# handar16.github.io
Repositori ini digunakan untuk menghosting situs personal menggunakan GitHub Pages.

# Cara menggunakan 
1. Pastikan file 'index.md' atau 'index.html' berada di root direktori.
2. Tunggu proses deployment otomatis dari GitHub Actions selesai.
3. Akses situs melalui url: https://handar16.github.io
